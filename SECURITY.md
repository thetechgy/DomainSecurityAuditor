# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

**Do not open public issues for security vulnerabilities.**

Use [GitHub's private vulnerability reporting](https://github.com/thetechgy/DomainSecurityAuditor/security/advisories/new) to submit security concerns.

Please include:

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Potential impact

**Response Timeline:**

- Acknowledgment: 48 hours
- Resolution target: 90 days
- Disclosure: Coordinated with reporter after fix is available
